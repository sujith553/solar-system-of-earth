# Solar System of Earth

## Overview
The Solar System project is a simple web-based project that provides a visual representation of the solar system, including the Sun and the planets.

## Features
- Displays the solar system using HTML.
- Provides a simple and user-friendly interface.
- Helps users learn about the planets and their arrangement.

## Technologies Used
- HTML5
- CSS3 (if used in the project)


## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/sujith553/solar-system-of-earth.git
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
